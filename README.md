# navilifesciences.com

Website for Navi Lifesciences Advisory Limited.

- Page content lives in `src/*.html` (one file per page, with a `<!--meta {...} -->` first line).
- Shared header, footer, SEO tags and navigation are in `build.js`.
- Styles: `assets/css/site.css`. Script (menu, form): `assets/js/site.js`. Images: `assets/img/`.

Build (macOS, nothing to install):

    osascript -l JavaScript build.js "$PWD"

This writes the finished site to `docs/`, which GitHub Pages serves.

Contact form: posts to FormSubmit (formsubmit.co) and is delivered to vivek.singh@navilifesciences.com.
